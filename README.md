
# 3D Living Room Project

A 3D Computer Graphics project developed using C++ and OpenGL as part of a team project.

## Features
- 3D living room environment
- Lighting effects
- 3D objects and camera transformations

## Technologies Used
- C++
- OpenGL
- GLFW
- GLAD
- GLM

## Teamwork
This project was developed collaboratively with my teammates as part of our Computer Graphics course. We worked together to apply 3D graphics concepts and create a virtual living room environment.

## My Contribution
I contributed to the development of the 3D graphics scene and the implementation of graphics concepts.
